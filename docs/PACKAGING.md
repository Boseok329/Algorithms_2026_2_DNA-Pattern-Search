# Source preservation and publication history

## Preserved experiment

The archived experiment was measured on November 4, 2026. The following files retain their recorded source bytes:

- Three original algorithm implementations in `originals/`.
- The counter-free timing variant in `code/kmp_timed.py`.
- Ninety input text files and six condition/reference JSON files.
- `conditions.csv`, `runs.csv`, and `summary.csv` under `results/20261104/`.

The three implementations, ninety inputs, and six reference files form the 99-file snapshot checked by `snapshot_manifest.json`. Original source comments and interfaces are retained for this comparison. English explanations of their APIs and use are provided in [CODE_GUIDE.md](CODE_GUIDE.md).

## Portable benchmark package

The repository runner checks the three included original implementations rather than an external source directory. Its input and reference checks retain the archived file hashes. Environment information for a new run is collected from the current machine.

Personal absolute paths were removed from the published snapshot manifest and environment metadata. Historical hashes were retained in the measurement record, while hashes for the portable scripts are stored separately in `package_code_sha256`. The original and packaged file hashes are listed in [source_provenance.json](source_provenance.json).

Consequently, the historical `input_manifest_sha256` refers to the original manifest and differs from the hash of the published, path-cleaned manifest. This difference does not indicate a change to the DNA inputs or expected positions.

## November 8, 2026 restoration

Seventy-two missing snapshot files were restored from the preserved experiment, together with the archived CSV files, figures, and historical verification record. All 99 snapshot files matched their recorded hashes. Full-position validation and saved-statistics verification passed after restoration. No new runtime benchmark was performed during that work.

`source_verification.json` preserves the historical verification record. `verification.json` reports checks against the portable package and is regenerated by `code/verify_results.py`. These records have different scopes and should not be treated as interchangeable.

## November 15, 2026 publication materials

The publication revision separates the personal Naive report (`README.md`) from the team comparison (`TEAM_REPORT.md`). It adds English documentation, a small runnable Naive example, a code-flow diagram, and English figures generated from the archived summary CSV.

- `examples/naive_demo.py` demonstrates the original implementation without duplicating its algorithm.
- `code/plot_figures.py` generates the personal and team figures from recorded summary values.
- `figures/naive/` contains Naive-only plots; `figures/team/` contains the comparison plots.
- The original plots remain under `results/20261104/charts/`.

These additions do not replace the archived implementations or measurements. They are documentation and presentation materials prepared after the experiment.
